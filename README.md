# โปรแกรมแจ้งผลการประเมินความสามารถผู้เรียน ระดับปฐมวัย หลักสูตร 2568

เว็บแอปพลิเคชัน (HTML/CSS/JavaScript ล้วน ไม่ต้อง build) ที่ย้ายจากไฟล์ Excel "โปรแกรมแจ้งผลการศึกษาปฐมวัย หลักสูตร 2568 สำเร็จรูป" (อนุบาล 1–3) มาเป็นเว็บ
เก็บข้อมูลบน Supabase · แยกข้อมูลตามโรงเรียน/ชั้น/ห้อง · ล็อกอินด้วย "รหัสสิทธิ์โรงเรียน"

> ระบบพี่น้อง: ระดับประถมศึกษา → `achievement2568primary` (repo นี้ไม่ได้แก้ไขหรือเชื่อมต่อกับระบบนั้น)

## โครงสร้างไฟล์
```
index.html          โปรแกรมหลัก (login + แอป)
admin.html          หน้าผู้ดูแล        register.html  หน้าสมัครใช้งาน
js/curriculum.js    8 ด้าน/33 ตัวชี้วัด/คำอธิบายพฤติกรรมบ่งชี้ อนุบาล 1-3 (สกัดจาก Excel)
js/engine.js        กติกาสรุปผล (ทดสอบด้วย node ได้)
js/report.js        สร้างเอกสารรายงาน      js/backend.js  เรียก Supabase RPC / โหมดทดลอง
js/app.js           หน้าจอหลัก             js/admin.js, js/register.js
sql/schema.sql      ตาราง RLS ฟังก์ชันทั้งหมด (รันซ้ำได้)
```

## ติดตั้ง
1. **Supabase** — SQL Editor → วาง `sql/schema.sql` → Run (โปรเจกต์ `achievement2568preprimary` รันไว้แล้ว)
2. **ตั้งรหัสผ่านผู้ดูแล** (ครั้งแรก): `select public.set_admin_password('รหัสผ่านยาวอย่างน้อย 10 ตัว');`
3. **js/config.js** — ใส่ `SUPABASE_URL` และ `SUPABASE_ANON_KEY` (anon key เปิดเผยได้ ความปลอดภัยอยู่ที่ RLS + ฟังก์ชัน)
4. **เผยแพร่** — โฮสต์ไฟล์ทั้งโฟลเดอร์บน static host ใดก็ได้ (GitHub Pages / Cloudflare Pages / Netlify)
5. เปิด `admin.html` → ออกรหัสให้โรงเรียน → ส่งรหัส `XXXX-XXXX-XXXX-XXXX` ให้โรงเรียนไปเข้า `index.html`
6. (ไม่บังคับ) ตั้ง GitHub Secrets `SUPABASE_URL`, `SUPABASE_ANON_KEY` ให้ `.github/workflows/keepalive.yml` ping กันโปรเจกต์ฟรีหยุดอัตโนมัติ

ถ้า `js/config.js` ไม่ระบุ Supabase เว็บจะทำงาน **โหมดทดลอง** (รหัส `DEMO` ข้อมูลอยู่ในเบราว์เซอร์เท่านั้น)

## ความปลอดภัย
- ทุกตารางเปิด RLS ไม่มี policy → เว็บอ่าน/เขียนตารางตรงไม่ได้ ทำได้เฉพาะผ่านฟังก์ชัน `app_*` / `admin_*` / `register_school`
- รหัสสิทธิ์เก็บเป็น SHA-256, รหัสผ่านผู้ดูแลเป็น bcrypt, จำกัดการเดารหัสต่อ IP (โรงเรียน 20 ครั้ง/10 นาที · ผู้ดูแล 10 ครั้ง/10 นาที)
- ฟังก์ชันออกรหัสโดยไม่ใช้รหัสผ่านผู้ดูแล (`issue_school` ฯลฯ) เรียกได้ใน SQL Editor เท่านั้น

## ข้อควรรู้ / สิ่งที่ยังไม่ได้ทำ
- ยังไม่มีระบบสั่งซื้อ/ตรวจสลิปอัตโนมัติแบบ `pay.html` ของระดับประถม (หน้าสมัครส่งคำขอให้ผู้ดูแลติดต่อกลับ)
- ไม่นำเข้าไฟล์ .xlsm เดิมโดยตรง (วางรายชื่อจาก Excel ได้)
- ตั้งค่าแพ็กเกจราคา/ช่องทางติดต่อที่ `js/config.js` → `SALES`
